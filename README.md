# Interactive Color Changer Checkpoint

A GoMyCode HTML, CSS, and JavaScript DOM checkpoint.

## Open

Download and extract this repository, then double-click `index.html`. No installation or build command is needed.

Click **Change Color** to give the box a random hexadecimal background color. The current color code is displayed underneath it.

## Requirements covered

- A `.container` containing the Color Changer heading.
- A fixed-size `#color-box` with a default background color.
- A labelled `#change-color-btn` button.
- Separate linked `styles.css` and `script.js` files.
- A `DOMContentLoaded` listener and `document.getElementById()` selections.
- `getRandomColor()` produces a six-digit hexadecimal color, including leading zeroes.
- A click listener updates the preview background and the displayed color code.

The button also supports keyboard activation. Random colors can occasionally repeat.
